# APU OpsLog — Live Connected GitHub Bundle

Your Google Apps Script live sheet URL is already configured inside `index.html`.

## How to Update Your GitHub Repository
1. Unzip this folder.
2. Open your public GitHub repository and click **Add file -> Upload files**.
3. Drag and drop all files (`index.html`, `manifest.json`, `sw.js`, `icon-192.png`, `icon-512.png`, `README.md`) to replace the old files, then click **Commit changes**.
4. Wait ~1 minute, refresh your GitHub Pages link, and submit a test entry — it will appear live in your Google Sheet and sync across all phones!
